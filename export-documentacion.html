📚 Documentación de Comandos

Guía completa de configuración para Cisco, Huawei y Fortinet

Cisco IOS - Configuración Completa
1. Acceso Inicial
enable configure terminal hostname ROUTER-SEDE1
Ingresa al modo privilegiado y accede a la configuración global
2. Configuración de VLANs
vlan 10 name VLAN-Datos vlan 20 name VLAN-Voz vlan 30 name VLAN-CCTV vlan 40 name VLAN-Servidores vlan 99 name VLAN-Gestion
Define las VLANs para cada servicio en la red
3. Configuración de Interfaces
interface GigabitEthernet0/0/1 description Link-to-SEDE2 ip address 172.16.0.1 255.255.248.0 no shutdown ! interface Vlan10 ip address 172.16.1.1 255.255.255.0 description VLAN-Datos
Configura las interfaces físicas y virtuales (SVI)
4. Enrutamiento OSPF
router ospf 1 network 172.16.0.0 0.0.7.255 area 0 network 172.16.8.0 0.0.3.255 area 0 default-information originate
Configura OSPF para enrutamiento dinámico entre sedes
5. Configuración de DHCP
ip dhcp pool VLAN10 network 172.16.1.0 255.255.255.0 default-router 172.16.0.1 dns-server 8.8.8.8 8.8.4.4 lease 7
Configura DHCP para asignación automática de IPs
6. Configuración de QoS
class-map match-any VOICE match dscp ef ! policy-map PRIORITY class VOICE priority 100 ! interface GigabitEthernet0/0/1 service-policy output PRIORITY
Prioriza tráfico de voz (EF - Expedited Forwarding)
7. Comandos de Verificación
show running-config show ip interface brief show ip route show vlan show ip ospf neighbor show ip dhcp binding
Verifica el estado de la configuración
💡 Nota: Siempre ejecuta write memory o copy running-config startup-config para guardar los cambios permanentemente.
Huawei VRP - Configuración Completa
1. Acceso Inicial
system-view sysName ROUTER-SEDE1 undo info-center enable
Ingresa a la vista del sistema y configura el nombre del dispositivo
2. Configuración de VLANs
vlan batch 10 20 30 40 99 ! vlan 10 name VLAN-Datos vlan 20 name VLAN-Voz
Crea VLANs en lotes para mayor eficiencia
3. Configuración de Interfaces
interface GigabitEthernet0/0/1 description Link-to-SEDE2 ip address 172.16.0.1 255.255.248.0 ! interface Vlanif10 ip address 172.16.1.1 255.255.255.0 description VLAN-Datos
Configura interfaces físicas y virtuales (Vlanif)
4. Enrutamiento OSPF
ospf 1 area 0.0.0.0 network 172.16.0.0 0.0.7.255 network 172.16.8.0 0.0.3.255
Configura OSPF en Huawei VRP
5. Configuración de DHCP
dhcp enable ! ip pool VLAN10 gateway-list 172.16.0.1 network 172.16.1.0 mask 255.255.255.0 dns-list 8.8.8.8 8.8.4.4 lease day 7
Habilita DHCP y crea pools de direcciones
6. Comandos de Verificación
display current-configuration display interface brief display ip routing-table display vlan display ospf peer
Verifica la configuración en Huawei
💡 Nota: En Huawei, usa quit para salir de la vista del sistema y save para guardar la configuración.
Fortinet FortiGate - Configuración Completa
1. Acceso Inicial
config system global set hostname FIREWALL-SEDE1 set timezone 04 end
Configura parámetros globales del firewall
2. Configuración de Interfaces
config system interface edit port1 set ip 172.16.0.1 255.255.248.0 set description Link-to-SEDE2 set allowaccess ping https ssh next edit port2 set ip 172.16.1.1 255.255.255.0 set description Internal-Network next end
Configura interfaces de red del firewall
3. Configuración de Enrutamiento
config router static edit 1 set destination 172.16.8.0 255.255.252.0 set gateway 172.16.0.2 set device port1 next end
Define rutas estáticas entre sedes
4. Configuración de Firewall Policy
config firewall policy edit 1 set srcintf port1 set dstintf port2 set srcaddr all set dstaddr all set action accept set schedule always set service ALL next end
Define políticas de firewall permitidas
5. Configuración de DHCP
config system dhcp server edit 1 set interface port2 set lease-time 604800 config ip-range edit 1 set start-ip 172.16.1.10 set end-ip 172.16.1.254 next end next end
Configura servidor DHCP en el firewall
6. Comandos de Verificación
get system status get system interface get router info routing-table all diagnose firewall policy list
Verifica el estado del firewall
⚠️ Advertencia: Siempre prueba las políticas de firewall antes de aplicarlas en producción. Un error puede bloquear el acceso a la red.

Recomendaciones por Caso de Uso
✅ Cisco IOS: Ideal para empresas grandes con infraestructura heterogénea. Excelente soporte, amplia documentación y comunidad activa.
✅ Huawei VRP: Buena opción para presupuestos limitados. Rendimiento similar a Cisco con menor costo. Creciente comunidad de soporte.
✅ Fortinet FortiGate: Especializado en seguridad y firewall. Mejor para organizaciones que priorizan protección perimetral y control de amenazas.
