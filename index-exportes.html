📋 Acerca de esta Documentación

Esta documentación completa contiene todo lo necesario para entender, implementar y mantener la infraestructura de red banda ancha para 3 sedes en Bogotá.

Contenido Incluido:

  • Dashboard: Visualización de la topología, estadísticas y tablas de referencia rápida
  • Generador: Herramienta interactiva para generar configuraciones por fabricante y sede
  • Documentación: Guías paso a paso con ejemplos reales de configuración
  • Auditoría: Análisis de cumplimiento y recomendaciones de mejora

Características Principales:

  • Diseño VLSM optimizado para 3 sedes con diferentes requisitos
  • Configuraciones auditadas para Cisco IOS, Huawei VRP y Fortinet FortiGate
  • Enrutamiento dinámico con OSPF
  • Segmentación por VLAN (Datos, Voz, CCTV, Servidores, Gestión)
  • Configuración de QoS para tráfico prioritario
  • Redundancia de enlaces WAN

Próximos Pasos Recomendados:

  • Revisar el Dashboard para entender la topología general
  • Usar el Generador para crear configuraciones específicas
  • Consultar la Documentación para detalles de cada comando
  • Implementar las recomendaciones del Reporte de Auditoría
🔧 Especificaciones Técnicas

Red Base:

  • Red: 172.16.0.0/16
  • Topología: VLSM (Variable Length Subnet Mask)
  • Protocolo de Enrutamiento: OSPF v2
  • Servicios: Datos, Voz, CCTV

Sedes:

  • Sede 1 (Teusaquillo): 172.16.0.0/21 - 1,600 hosts
  • Sede 2 (Campus U Compensar): 172.16.8.0/22 - 600 hosts
  • Sede 3 (AV68): 172.16.12.0/23 - 400 hosts

Enlaces WAN:

  • S1 ↔ S2: Fibra Óptica Dedicada 100 Mbps (Primario)
  • S2 ↔ S3: Fibra Óptica Dedicada 100 Mbps (Primario)
  • S1 ↔ S3: MPLS VPN 50 Mbps (Respaldo)
