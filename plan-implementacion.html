Requisitos Previos
Antes de comenzar, asegúrate de tener:
  • Backup de configuración actual realizado
  • Acceso SSH verificado en todos los dispositivos
  • Contraseñas de administrador confirmadas
  • Ventana de mantenimiento programada
  • Equipo de soporte disponible
Arquitectura General

La red está diseñada con VLSM (Variable Length Subnet Mask) para optimizar el uso de direcciones IP:

Sede Ubicación Red Hosts Requeridos Hosts Disponibles
Sede 1 Teusaquillo 172.16.0.0/21 1,600 2,046
Sede 2 Campus U Compensar 172.16.8.0/22 600 1,022
Sede 3 AV68 172.16.12.0/23 400 510
Fases de Implementación

Fase 1: Preparación (30 minutos)

  • Realizar backup de configuración actual
  • Verificar conectividad básica
  • Documentar estado actual

Fase 2: Configuración Inicial (45 minutos)

  • Configurar nombre del dispositivo
  • Crear VLANs
  • Configurar interfaces físicas y virtuales

Fase 3: Enrutamiento (30 minutos)

  • Habilitar OSPF
  • Configurar vecinos OSPF
  • Verificar adyacencias

Fase 4: Servicios (30 minutos)

  • Configurar DHCP
  • Configurar QoS
  • Aplicar políticas

Fase 5: Verificación (20 minutos)

  • Verificar configuración
  • Pruebas de conectividad
  • Verificar OSPF y servicios

↩️ Procedimientos de Rollback
Matriz de Decisión
Problema Severidad Tiempo Acción Recomendada
Comando incorrecto Baja 5 min Rollback rápido (no comando)
Interfaz DOWN Media 10 min Reconfigurar interfaz
OSPF no funciona Media 20 min Rollback parcial OSPF
Todas interfaces DOWN Alta 30 min Restaurar desde backup
Dispositivo no responde Crítica 60 min Acceso consola + restaurar imagen
